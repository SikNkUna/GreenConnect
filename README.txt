GreenClimateConnect website

FILES
- index.html: page structure and content
- css/style.css: colours, layout, typography and responsive styling
- js/script.js: product display, search, category filters and shopping basket

HOW TO EDIT
1. Extract this folder from the ZIP file.
2. Open the folder in a code editor such as Visual Studio Code.
3. Open index.html in your browser to preview the website.
4. Edit the HTML, CSS or JavaScript file as needed, then refresh the browser.

NOTES
- Product names, descriptions, prices and image URLs are in js/script.js.
- Contact details and footer text are in index.html.
- The email and phone number currently shown are sample details.
- Product images are loaded from Unsplash, so an internet connection is needed to display them.
- Checkout currently opens an email enquiry; it does not process payments.
